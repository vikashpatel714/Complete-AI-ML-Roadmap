🧠 Neural Networks from Zero

Visual notes for complete beginners: touch the sliders, press the buttons, watch it work. Read top to bottom once, then use the cheat sheet at the end for quick revision.

1. Neuron: the tiny decision maker

Idea: multiply each input by its weight (importance), add a bias (starting push), then squash with an activation (sigmoid gives 0 to 1).

2. Perceptron: one neuron that learns a line

A perceptron guesses 0 or 1. When it is wrong, it nudges weights: w = w + lr × error × x. Colour = what it predicts. Dots: green = should be 1, pink = should be 0.

Try XOR: it never settles. One straight line cannot separate it, so we need layers (next section).

3. Multilayer Perceptron & Feed-Forward

Stack neurons in layers: input → hidden → output. Data only moves forward (feed-forward). Hidden layers let the network bend the line and solve harder problems. Brightness = how strongly a neuron fires.

Blue lines = positive weights, pink = negative; thicker = stronger. Activation functions: sigmoid (0 to 1), tanh (−1 to 1), ReLU (max(0, z), the most common today).

4. Backpropagation: how a network learns

1 Forward pass: predict2 Loss: how wrong?3 Backward: blame each weight4 Update: w = w − lr × gradient

Chain rule: dLoss/dw = dLoss/dy × dy/dz × dz/dw. The error is sent backwards layer by layer, telling each weight which way to move. Simulation: loss = (w − 3)², the best weight is 3. The ball rolls downhill.

Tiny lr = slow. Good lr = smooth. lr above 1 = ball jumps out and diverges.

5. Recurrent Neural Network (RNN): a network with memory

Normal networks forget the past. An RNN passes a hidden state h from one step to the next, so it can read sequences (words, sound, prices). Formula: h(t) = tanh(Wxh·x(t) + Whh·h(t−1) + b) and y(t) = Why·h(t).

BPTT = backpropagation on the unrolled network: the error flows back through every time step. Each step multiplies the gradient by a number below 1, so the oldest words get almost no learning signal (vanishing gradient). LSTM and GRU fix this with gates.

6. Hyper-parameter tuning

Parameters (weights) are learned by the network. Hyper-parameters are settings YOU choose before training.

Learning rate
Step size (section 4 demo). Most important.
Batch size
Samples seen before one update: 16, 32, 64.
Epochs
Full passes over data. Too many = overfitting.
Layers & neurons
Bigger = more power but more overfit risk.
Dropout
Randomly switch off neurons (0.2 to 0.5) to avoid overfitting.
Optimizer
SGD, Adam (a safe default), RMSprop.

How to search

Grid search: try every combinationRandom search: faster, often betterBayesian: learns from past trialsAlways tune on a validation set, never the test set

8. Text classification

Pipeline: Text → tokens (words) → numbers (embeddings) → RNN / CNN → class. Mini demo: every word has a score; the sum decides positive or negative sentiment (a tiny model of what a real network learns).

9. Case studies

🏥 Health care
Data: X-ray, skin and retina images, patient records.
Model: CNN for images, RNN for vital-sign time series.
Result: early disease detection, e.g. diabetic foot ulcer or tumour classification.
🛒 E-commerce
Data: clicks, purchases, reviews, product photos.
Model: MLP/RNN for recommendations, text classification for reviews, CNN for visual search.
Result: “you may also like”, fake-review detection, demand forecasts.
🏙️ Smart cities
Data: traffic cameras, sensors, power meters.
Model: CNN counts vehicles, RNN predicts traffic and energy use.
Result: smart signals, less jam, waste and energy savings.
