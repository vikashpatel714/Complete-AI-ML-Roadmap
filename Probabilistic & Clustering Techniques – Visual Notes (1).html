🎲 Probabilistic & Clustering Techniques

Module 4 for complete beginners: Bayes, Naive Bayes, belief networks, tree ensembles (Random Forest, AdaBoost, Gradient Boosting, XGBoost), K-Means, K-Medoids, K-Modes and hierarchical clustering. Play with every demo, then use the cheat sheet to revise.

1. Bayesian learning: update your belief with evidence

P(A|B) = P(B|A) × P(A) / P(B). Start with a prior belief, see evidence, get a posterior belief. Example: a medical test. Even a good test can mislead when the disease is rare. Move the sliders.

2. Naive Bayes classifier

Pick the class with the highest P(class) × P(word1|class) × P(word2|class) × …. “Naive” = it assumes words are independent, which is simple, fast and works surprisingly well (spam filters). Tap words in an email:

3. Bayesian belief network

A graph where arrows mean “influences”. Each node stores a probability table. Rain may switch the sprinkler off, and both can wet the grass. Set evidence (what you observed) and watch every other probability update. Try: Grass wet = true, then Rain = false.

5. Random Forest

Bagging + one extra trick: each split looks at a random subset of features, so trees differ. Final answer = majority vote. Each weak tree below is right only 62% of the time. Add trees and watch accuracy rise.

6. AdaBoost

Start with equal sample weights. Each round: train a tiny “stump” (one split), give it a vote weight α (more accurate = bigger α), then increase the weight of misclassified points. Dot size = weight. Green/pink = two classes; the line is the stump.

7. Gradient Boosting & XGBoost

Start with a simple guess (the average). Each new tree learns the residual (what is still wrong) and adds a small correction: new prediction = old + learning rate × tree. Click Add tree repeatedly.

XGBoost = Gradient Boosting, engineered

Regularization

8. Unsupervised learning, clustering & distance measures

No labels! The algorithm groups similar items by itself (customer segments, news topics). “Similar” means “close”, so we need a distance. Move points A and B:

Euclidean = straight line. Manhattan = city blocks. Cosine = difference in direction (good for text).

9. K-Means clustering

1 Pick K centroids2 Assign each point to the nearest centroid3 Move centroid to the mean4 Repeat until nothing changes

Objective: minimise J = Σ ‖point − its centroid‖². Squares = centroids. Press Step twice to see assign, then move. Initialization matters: press “New random init” a few times; bad starts can give bad clusters. The fix is K-Means++ (spread the starting centroids far apart).

Choosing K: the elbow method

Run K-Means for K = 1 to 7 and plot J. Pick the “elbow” where the drop slows down (here K = 3). Yellow dot = your current K.

10. K-Medoids & K-Modes

K-Medoids (PAM)
The centre must be a real data point (medoid). It is robust to outliers because the mean is not used.
K-Modes
For categorical data (colour, size). Centre = most frequent value (mode). Distance = number of mismatches.

11. Hierarchical clustering

Builds a tree of clusters (a dendrogram) so you need not choose K first. Cut the tree at any height to get clusters. Linkage = how to measure distance between two clusters: Single = closest pair (can chain), Complete = farthest pair (compact balls).

Dashed line = your cut. The leaves are the numbered points; a taller join means the clusters were farther apart.

AGNES vs DIANA (number = clusters left)

AGNES (Agglomerative Nesting, bottom-up): every point starts alone, repeatedly merge the two closest clusters.

DIANA (Divisive Analysis, top-down): start with one big cluster, repeatedly split the most spread-out cluster.
